AKATSUKI DUSK — ENDCORD THEME

This pack contains:
- Akatsuki-Dusk.json: Spec 2 theme with an image-background URL.
- Akatsuki-Dusk-Wallpaper.png: the background image.

IMPORTANT — GitHub upload order:
1. Create a PUBLIC repository named exactly: Akatsuki-Dusk
2. Upload BOTH files to the repository root:
   - Akatsuki-Dusk.json
   - Akatsuki-Dusk-Wallpaper.png
3. Commit the files.
4. In Endcord > Themes > +, paste this theme URL:
   https://raw.githubusercontent.com/fyzahrenayong-cell/Akatsuki-Dusk/main/Akatsuki-Dusk.json

The JSON already points to the matching wallpaper's raw GitHub URL.
The wallpaper will load only after it is uploaded to that exact repository,
with that exact filename, on the main branch.

Palette: smoky plum, charcoal, muted crimson, warm pale text.
